# Dutra Doces — site

Página "Em breve" estática (HTML + CSS), publicada pela Vercel a cada push na branch `main`.

- `index.html` — página
- `assets/` — logo, padrão xadrez da caixa, selo e favicon
- `vercel.json` — configuração da Vercel (URLs limpas)

Cores da marca: café `#231f20` · ouro `#d69215` · branco `#ffffff`
Fontes: Oswald (títulos) e Bodoni Moda (texto), via Google Fonts.

## Checkout

Página de pagamento em `checkout/` (publicada em `checkout.dutradoces.com.br/checkout`). Configuração, testes e publicação: veja [`checkout/README.md`](checkout/README.md).
